# 🏫 郑州大学 · 校园记忆

> 廉花郑放·赓续清风——红色廉洁文化档案展暨第十九个"6·9"国际档案日庆祝活动

一个静态展示页面，汇集郑州大学珍贵的历史影像与校园回忆录，通过镜头回溯那些年在郑大走过的路、看过的风景、遇见的人。

🔗 **在线预览**：[https://leap-w.github.io/zzu-oldphotos1/](https://leap-w.github.io/zzu-oldphotos1/)

---

## 📋 项目简介

本项目为郑州大学红色廉洁文化档案展的线上展示页面，旨在：

- 📺 整合郑州大学官方视频号《时光里的郑大》系列内容
- ✂️ 展示自主搜集剪辑的校园历史影像
- 🎓 传承郑大精神，唤醒校友青春记忆
- 📚 配合线下档案展览，提供线上观展渠道

---

## 🎬 页面内容

| 板块 | 说明 |
|------|------|
| **时光里的郑大** | 郑州大学官方视频号出品，第一期与第二期珍贵历史影像 |
| **自主剪辑作品** | 搜集整理的校园影像素材，自主剪辑制作《郑大岁月·校园记忆》 |

## 🚀 本地运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/Leap-w/zzu-oldphotos1.git
   ```

2. 直接在浏览器中打开 `index.html`，或使用任意静态服务器：
   ```bash
   # 使用 Python
   python -m http.server 8000

   # 使用 Node.js (npx)
   npx serve .
   ```

3. 访问 `http://localhost:8000` 即可预览。
